# Security Hardening

## Overview

**Security hardening** is the process of strengthening a system to reduce its **vulnerabilities** and **attack surface**.

Security analysts use security hardening to proactively protect systems, networks, and devices from attacks. The goal is to minimize potential vulnerabilities and reduce the number of successful attacks.

## Attack Surface

**Attack Surface:** The total set of potential vulnerabilities or entry points that a threat actor could exploit to gain access to a system.

### Example

A network can be compared to a house:

- **Doors and windows** represent potential entry points.
- A robber could use these entry points to access the house.
- Locks on the doors and windows reduce the possibility of unauthorized access.

Similarly, security hardening reduces the attack surface by securing potential entry points and vulnerabilities.

## Areas of Security Hardening

Security hardening can be applied to any device or system that could be compromised, including:

- Hardware
- Operating systems
- Applications
- Computer networks
- Databases
- Physical spaces

### Physical Security

Physical security is also part of security hardening. Examples include:

- Security cameras
- Security guards
- Securing physical spaces

## Common Security Hardening Procedures

### 1. Software Updates and Patches

Software updates, also called **patches**, help:

- Increase security
- Fix security vulnerabilities
- Keep systems functioning securely and optimally

### 2. Configuration Changes

Security can be improved by modifying device and application configurations.

Examples include:

- Requiring longer passwords
- Requiring more frequent password changes
- Updating encryption standards for stored database data

These changes make it more difficult for malicious actors to obtain login credentials or access protected data.

### 3. Removing Unused Applications and Services

Unused applications and services should be removed or disabled when they are not required.

Reducing the number of applications and services can:

- Reduce the attack surface
- Make system and network monitoring more efficient
- Reduce potential opportunities for exploitation

### 4. Disabling Unused Ports

Unused network ports should be disabled to reduce potential entry points that could be exploited by threat actors.

### 5. Reducing Access Permissions

Access permissions should be reduced across devices and networks where appropriate.

Minimizing unnecessary permissions helps reduce the attack surface and makes monitoring more efficient.

## Penetration Testing

Another important security hardening strategy is **regular penetration testing**.

**Penetration Test (Pen Test):** A simulated attack used to identify vulnerabilities in a system, network, website, application, or process.

### Penetration Testing Process

1. A penetration test simulates an attack against the target.
2. Penetration testers identify vulnerabilities.
3. The testers document their findings in a report.
4. Security teams review the identified vulnerabilities.
5. Organizations develop a plan to fix the vulnerabilities.

Penetration testing helps organizations determine which security vulnerabilities require attention and remediation.

## Key Takeaways

- **Security hardening** strengthens systems to reduce vulnerabilities and the attack surface.
- The **attack surface** consists of potential vulnerabilities or entry points that a threat actor could exploit.
- Hardening can be applied to hardware, operating systems, applications, networks, databases, and physical spaces.
- Common hardening techniques include:
  - Applying software updates and patches
  - Making secure configuration changes
  - Removing or disabling unused applications and services
  - Disabling unused ports
  - Reducing unnecessary access permissions
  - Maintaining up-to-date encryption standards
- **Penetration testing** simulates attacks to identify vulnerabilities that need to be fixed.
- Reducing the attack surface improves security and makes monitoring systems more efficient.
