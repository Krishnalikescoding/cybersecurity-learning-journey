# Course 2 - Module 2: Key Terms

| Term | Definition |
|------|------------|
| **Address Resolution Protocol (ARP)** | A network protocol used to determine the **MAC address** of the next router or device on the path. |
| **Cloud-based Firewalls** | Software firewalls hosted and managed by a cloud service provider. |
| **Controlled Zone** | A subnet that protects the internal network from the uncontrolled zone. |
| **Domain Name System (DNS)** | A networking protocol that translates domain names into IP addresses. |
| **Encapsulation** | A VPN process that protects data by wrapping sensitive information inside encrypted data packets. |
| **Firewall** | A network security device that monitors and filters incoming and outgoing network traffic. |
| **Forward Proxy Server** | A server that regulates and restricts users' access to the internet by forwarding outgoing requests. |
| **Hypertext Transfer Protocol (HTTP)** | An application layer protocol used for communication between web browsers and web servers. |
| **Hypertext Transfer Protocol Secure (HTTPS)** | A secure version of HTTP that encrypts communication between clients and servers. |
| **IEEE 802.11 (Wi-Fi)** | A family of standards that define wireless LAN (Wi-Fi) communication. |
| **Network Protocols** | A set of rules that define how devices communicate and exchange data over a network. |
| **Network Segmentation** | A security technique that divides a network into smaller segments to improve security and performance. |
| **Port Filtering** | A firewall function that blocks or allows traffic based on port numbers. |
| **Proxy Server** | A server that receives client requests and forwards them to other servers while providing security and filtering. |
| **Reverse Proxy Server** | A server that regulates and restricts external access to internal servers. |
| **Secure File Transfer Protocol (SFTP)** | A secure protocol used to transfer files over a network. |
| **Secure Shell (SSH)** | A security protocol used to securely access and manage remote systems. |
| **Security Zone** | A protected segment of a network with specific access controls and security policies. |
| **Simple Network Management Protocol (SNMP)** | A protocol used to monitor and manage devices on a network. |
| **Stateful Firewall** | A firewall that tracks active network connections and filters traffic based on connection state. |
| **Stateless Firewall** | A firewall that filters traffic using predefined rules without tracking active connections. |
| **Subnetting** | The process of dividing a network into smaller logical networks called subnets. |
| **Transmission Control Protocol (TCP)** | A reliable, connection-oriented protocol used for transmitting data between devices. |
| **Uncontrolled Zone** | The part of a network outside the organization's control, such as the Internet. |
| **Virtual Private Network (VPN)** | A service that encrypts internet traffic, hides the public IP address, and masks the user's virtual location. |
| **Wi-Fi Protected Access (WPA)** | A wireless security protocol used to secure Wi-Fi networks. |

---

# Quick Revision

- **ARP** → Maps IP addresses to MAC addresses.
- **DNS** → Converts domain names into IP addresses.
- **HTTP / HTTPS** → Web communication (HTTPS is encrypted).
- **TCP** → Reliable, connection-oriented communication.
- **SSH** → Secure remote system access.
- **SFTP** → Secure file transfer.
- **SNMP** → Network monitoring and management.
- **Firewall** → Filters network traffic.
- **Stateful Firewall** → Tracks active connections.
- **Stateless Firewall** → Uses predefined filtering rules only.
- **Proxy Server** → Intermediary that forwards and filters requests.
- **Forward Proxy** → Protects internal users.
- **Reverse Proxy** → Protects internal servers.
- **VPN** → Encrypts traffic and hides public IP addresses.
- **Encapsulation** → Wraps encrypted data inside another packet.
- **Network Segmentation** → Divides a network into smaller secure segments.
- **Subnetting** → Creates smaller subnetworks within a larger network.
- **Security Zone** → Protected section of a network.
- **Controlled Zone** → Internal protected subnet.
- **Uncontrolled Zone** → External public network (Internet).
- **Port Filtering** → Allows or blocks traffic by port number.
- **Cloud-based Firewall** → Firewall hosted in the cloud.
- **IEEE 802.11** → Wi-Fi networking standard.
- **WPA** → Wireless security protocol for Wi-Fi.
