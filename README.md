A structured collection of my personal study notes, summaries, and learning resources from the **Google Cybersecurity Professional Certificate** on Coursera.

I completed all nine courses in the certificate program and organized this repository to make the concepts easier to understand, revise, and revisit.

The folders in this repository may appear in a different order on GitHub. Follow the roadmap below for the recommended learning sequence.

> **Note:** These are personal learning notes created for educational purposes. They are not official Google or Coursera course materials.

## 📖 Topics Covered

The repository contains notes covering the following areas:

- **Cybersecurity Fundamentals:** Security concepts, security professionals, and the cybersecurity landscape.
- **Security Risk Management:** Security risks, frameworks, controls, and risk assessment.
- **Network Security:** Networking fundamentals, network protocols, and network protection.
- **Linux and SQL:** Command-line operations, Linux commands, and database querying.
- **Assets, Threats, and Vulnerabilities:** Threat actors, vulnerabilities, risk identification, and mitigation.
- **Detection and Response:** Security monitoring, SIEM tools, IDS, incident detection, and response.
- **Python for Cybersecurity:** Python fundamentals and automation of security tasks.
- **Cybersecurity Careers:** Preparing for entry-level cybersecurity roles.
