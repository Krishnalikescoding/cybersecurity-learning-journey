# Attacker Mindset & Threat Simulations – Notes

## Applying an Attacker Mindset
- Comes after identifying vulnerabilities (via vulnerability assessments).
- Like conducting an experiment — cause problems in a controlled environment, evaluate outcomes.
- Offers a different perspective on security challenges; insights help build/modify security plans.

## Attack Simulations
Two main approaches, both aiming to make systems safer:

### Proactive Simulations (Red Team)
- Play the role of the **attacker** — exploit vulnerabilities, break through defenses.
- Spend more time **planning** than performing.
- Example tactic: phishing staff with fake emails to test security awareness.

### Reactive Simulations (Blue Team)
- Play the role of the **defender** responding to an attack.
- Focus on gathering info about assets being protected.
- Commonly use **vulnerability scanning tools**.

## Scanning for Trouble
- **Vulnerability scanner**: software that compares known CVEs against network technologies.
- Reactive simulations often use scan results to assess risk and plan remediation.

### Example: Reactive Simulation Workflow (external scan)
1. **Identification** – flag a vulnerable server (e.g., outdated OS)
2. **Vulnerability analysis** – research the outdated OS's known vulnerabilities
3. **Risk assessment** – score severity, evaluate impact of not fixing
4. **Remediation** – use findings to address the issue

- Findings are typically compiled into a **report** for service providers/supervisors.
- Clear communication of results is a key professional skill.

## Finding Innovative Solutions
- Many security controls exist as reactive responses to past risks — criminals keep finding new bypasses.
- Staying current on trends/tech is essential.
- **Pro tip**: NIST's **National Vulnerability Database (NVD)** is a useful resource for tracking common vulnerabilities.

## Key Takeaways
- Vulnerability assessments are central to security risk planning.
- Analysts participate in both proactive and reactive simulations.
- Knowing common vulnerabilities isn't enough — staying informed on new technologies/innovative thinking matters too.
