# Cryptojacking 

## Malware Evolution
- Early malware: digital vandalism.
- Modern malware: profitable crime for financial gain (e.g., ransomware, cryptojacking).

## What is Cryptojacking?
- Malware that installs software to **illegally mine cryptocurrency**.
- **Crypto mining**: process of obtaining new coins/tokens by using computers to process (dig through) billions of lines of encrypted code — more computers mining = more coins found.
- Criminals exploit this by hijacking others' computing power instead of paying for it themselves.

## How It Spreads
- Began in **2017**, targeting personal computers.
- Now more sophisticated: attackers target **vulnerable servers**.
- Any device that communicates with an infected server can also become infected.
- Malicious code mines coins **silently in the background**.

## Detection

### Intrusion Detection System (IDS)
- Application that monitors system activity and alerts on possible intrusions.
- Flags abnormal activity (e.g., malware mining coins).
- **Drawback**: new/unknown forms of malware can slip past detection.

### Warning Signs of Infection
- **Slowdown** (most telling sign)
- Increased CPU usage
- Sudden system crashes
- Fast-draining batteries
- Unusually high electricity costs (due to resource-intensive mining)

## Prevention Measures
- Use browser extensions that block malware
- Use ad blockers
- Disable JavaScript
- Stay alert on latest malware trends
- Security analysts should educate others in the organization

## Key Takeaways
- Cryptojacking is a relatively new but growing threat.
- Malicious code continues to evolve, requiring ongoing vigilance.
- Recognizing signs and prevention measures helps defend against it, even without deep malware analysis expertise.
