# Module 2: Key Terms and Definitions

## 1. Network Fundamentals
- **Data Packet:** The basic unit of information that travels between devices on a network.
- **Network Data:** Data transmitted between devices on a network.
- **Network Traffic:** The amount of data moving across a network.
- **Internet Protocol (IP):** A set of standards used for addressing and routing packets between devices.
- **MAC Address (Media Access Control Address):** A unique identifier assigned to a network interface.
- **NIC (Network Interface Card):** Hardware that connects a computer to a network.

## 2. Network Monitoring and Analysis
- **Network Protocol Analyzer (Packet Sniffer):** A tool used to capture and analyze network traffic.
- **Packet Sniffing:** The practice of capturing and inspecting network packets.
- **Packet Capture (P-cap):** A file containing packets captured from a network interface or network.
- **Wireshark:** An open-source network protocol analyzer with a graphical user interface.
- **tcpdump:** A command-line network protocol analyzer used to capture and inspect network traffic.
- **CLI (Command-Line Interface):** A text-based interface that allows users to interact with a computer using commands.

## 3. Security Concepts
- **Command and Control (C2):** Techniques used by malicious actors to maintain communication with compromised systems.
- **Data Exfiltration:** Unauthorized transmission of data from a system.
- **Indicators of Compromise (IoCs):** Observable evidence that suggests a potential security incident.
- **IDS (Intrusion Detection System):** An application that monitors system activity and alerts on possible intrusions.

## 4. System Privileges
- **Root User (Superuser):** A user with elevated privileges to modify and manage a system.
- **Sudo:** A command that allows authorized users to execute commands with elevated privileges.

## 5. Incident Response
- **NIST Incident Response Lifecycle:** A framework consisting of four phases:
  1. Preparation
  2. Detection and Analysis
  3. Containment, Eradication, and Recovery
  4. Post-incident Activity

- **Playbook:** A manual containing instructions for performing specific operational actions.

## 6. Quick Revision
- **C2:** Communication between attackers and compromised systems.
- **Data Exfiltration:** Unauthorized data transfer out of a system.
- **IoCs:** Evidence of a possible security incident.
- **IDS:** Detects suspicious activity and generates alerts.
- **Wireshark:** GUI-based packet analysis tool.
- **tcpdump:** CLI-based packet analysis tool.
- **NIC:** Connects a computer to a network.
- **P-cap:** Stores captured network packets.
- **Root:** Elevated system privileges.
- **sudo:** Executes authorized commands with elevated privileges.
