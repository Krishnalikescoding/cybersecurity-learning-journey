# Log Management

## Logs
- **Log:** A record of events occurring within an organization's systems.
- **Log Entry:** Details about a single event on a device or system.
- **Log Analysis:** Examining logs to identify events of interest and investigate security incidents.
- Logs help investigate the **5 W's:** Who, What, When, Where, and Why.
- **SIEM:** Collects and consolidates logs into a central location for security analysis.

## Types of Logs

1. **Network Logs:** Generated by firewalls, routers, and switches.
2. **System Logs:** Generated by operating systems like Windows and Linux.
3. **Application Logs:** Record events occurring within software applications.
4. **Security Logs:** Record security-related events, such as file deletion or antivirus alerts.
5. **Authentication Logs:** Record authentication events, such as successful or failed login attempts.

## Log Details
Logs commonly contain:
- Date and time
- Location or source
- Action performed
- User or author responsible

**Verbose Logging:** Records additional details beyond standard logs, such as timestamps, source code locations, device names, and IP addresses.

## Log Management

**Log management:** The process of collecting, storing, analyzing, and disposing of log data.

### What to Log
- Select log sources relevant to security investigations.
- Configure logging to capture useful information without unnecessary details.
- Handle **Personally Identifiable Information (PII)**, such as names, phone numbers, and email addresses, carefully.

### Overlogging
Recording excessive amounts of unnecessary log data.

**Disadvantages:**
- Increased storage and maintenance costs.
- Higher system resource usage and performance issues.
- Difficulty searching for important security events.
- Reduced efficiency of log analysis.

**Best practice:** Log relevant information rather than everything.

### Log Retention
**Log retention:** Keeping logs for a specified period according to organizational needs and regulatory requirements.

Examples of relevant regulations and standards:
- **FISMA:** Public sector and federal information security.
- **HIPAA:** Healthcare information protection.
- **PCI DSS:** Payment card data security.
- **GLBA:** Protection of consumer financial information.
- **SOX:** Financial reporting and accountability.

### Log Protection
Logs must be protected against unauthorized access, modification, and deletion.

- **Centralized Log Server:** Stores logs on a dedicated server instead of individual devices.
- Centralized storage makes it harder for attackers to modify or delete logs on compromised machines.
- Maintaining log integrity helps security teams investigate incidents accurately.

## Key Takeaways
- Logs provide evidence for detecting and investigating security incidents.
- Log management includes collection, storage, analysis, and disposal.
- Avoid overlogging to reduce costs and improve search efficiency.
- Follow appropriate log retention requirements.
- Use centralized storage and access controls to protect log integrity.
