# Course 6: Terms and Definitions

## A
- **Advanced Persistent Threat (APT):** An attack in which a threat actor maintains unauthorized access to a system for an extended period.
- **Analysis:** Investigation and validation of security alerts.
- **Anomaly-Based Analysis:** A detection method that identifies abnormal behavior.
- **Array:** A data type that stores data in an ordered list.

## B
- **Broken Chain of Custody:** Inconsistencies in collecting and recording evidence.
- **Business Continuity Plan (BCP):** A document outlining procedures to maintain business operations during and after major disruptions.

## C
- **Chain of Custody:** Documentation of evidence possession and control throughout an incident lifecycle.
- **Command and Control (C2):** Techniques used by malicious actors to communicate with compromised systems.
- **Command-Line Interface (CLI):** A text-based interface that uses commands to interact with a computer.
- **Common Event Format (CEF):** A log format that uses structured fields and key-value pairs to organize event data.
- **Computer Security Incident Response Team (CSIRT):** A specialized team of security professionals trained in incident management and response.
- **Configuration File:** A file used to configure an application's settings.
- **Containment:** Limiting and preventing further damage caused by an incident.
- **Crowdsourcing:** Gathering information through public input and collaboration.

## D
- **Data Exfiltration:** Unauthorized transmission or transfer of data from a system.
- **Data Packet:** A basic unit of information transmitted between devices over a network.
- **Detection:** Prompt discovery of security events.
- **Documentation:** Recorded content used for a specific purpose.

## E
- **Endpoint:** Any device connected to a network.
- **Endpoint Detection and Response (EDR):** An application that monitors endpoints for malicious activity.
- **Eradication:** Complete removal of incident-related threats from affected systems.
- **Event:** An observable occurrence on a network, system, or device.

## F
- **False Negative:** A situation where an actual threat is not detected.
- **False Positive:** An alert that incorrectly identifies normal activity as a threat.
- **Final Report:** Documentation providing a comprehensive review of an incident.

## H
- **Honeypot:** A decoy system or resource designed to attract attackers.
- **Host-Based Intrusion Detection System (HIDS):** An application that monitors the activity of the host on which it is installed.

## I
- **Incident:** An occurrence that threatens the confidentiality, integrity, or availability (CIA) of information or systems, or violates security policies or laws.
- **Incident Handler's Journal:** Documentation used to record details and activities during incident response.
- **Incident Response Plan:** A document outlining procedures for each stage of incident response.
- **Indicators of Attack (IoA):** Observed events or behaviors indicating an ongoing attack.
- **Indicators of Compromise (IoC):** Observable evidence suggesting a potential security incident.
- **Internet Protocol (IP):** A set of standards used for routing and addressing data packets between network devices.
- **Intrusion Detection System (IDS):** An application that monitors system activity and alerts on possible intrusions.
- **Intrusion Prevention System (IPS):** An application that monitors for intrusive activity and takes action to stop it.

## K
- **Key-Value Pair:** Two linked items consisting of a key and its corresponding value.

## L
- **Lessons Learned Meeting:** A meeting involving all relevant parties after a major incident to evaluate the response and identify improvements.
- **Log Analysis:** Examining logs to identify events of interest.
- **Log Management:** Collecting, storing, analyzing, and disposing of log data.
- **Logging:** Recording events occurring on computer systems and networks.

## M
- **Media Access Control (MAC) Address:** A unique identifier assigned to a network interface for communication on a network.

## N
- **National Institute of Standards and Technology (NIST) Incident Response Lifecycle:** A framework consisting of four phases:
  1. Preparation
  2. Detection and Analysis
  3. Containment, Eradication, and Recovery
  4. Post-Incident Activity
- **Network-Based Intrusion Detection System (NIDS):** An application that collects and monitors network traffic and data.
- **Network Data:** Data transmitted between devices on a network.
- **Network Interface Card (NIC):** Hardware that connects a computer to a network.
- **Network Protocol Analyzer (Packet Sniffer):** A tool used to capture and analyze network traffic.
- **Network Traffic:** The amount of data moving across a network.

## O
- **Object:** A data type that stores data in a collection of key-value pairs.
- **Open-Source Intelligence (OSINT):** Collecting and analyzing publicly available information to generate useful intelligence.

## P
- **Packet Capture (PCAP):** A file containing data packets captured from a network interface or network.
- **Packet Sniffing:** Capturing and inspecting data packets travelling across a network.
- **Playbook:** A manual containing detailed instructions for operational actions.
- **Post-Incident Activity:** Reviewing an incident to identify improvements in incident handling.

## R
- **Recovery:** Returning affected systems to normal operations.
- **Resilience:** The ability to prepare for, respond to, and recover from disruptions.
- **Root User (Superuser):** A user with elevated privileges to modify and control a system.

## S
- **Search Processing Language (SPL):** Splunk's query language used to search and analyze data.
- **Security Information and Event Management (SIEM):** A tool that collects and analyzes log data to monitor critical organizational activities.
- **Security Operations Center (SOC):** An organizational unit dedicated to monitoring networks, systems, and devices for security threats.
- **Security Orchestration, Automation, and Response (SOAR):** A collection of tools and workflows that uses automation to respond to security events.
- **Signature:** A pattern associated with malicious activity.
- **Signature Analysis:** A detection method that identifies events by matching activity against known signatures.
- **Standards:** References that guide the creation of policies and procedures.
- **Sudo:** A command that temporarily grants elevated privileges to authorized users.
- **Suricata:** An open-source intrusion detection and prevention system.

## T
- **tcpdump:** A command-line network protocol analyzer used to capture and inspect network traffic.
- **Telemetry:** Collection and transmission of data for analysis.
- **Threat Hunting:** Proactively searching for threats within a network.
- **Threat Intelligence:** Evidence-based information that provides context about existing or emerging threats.
- **Triage:** Prioritizing incidents according to their importance or urgency.
- **True Negative:** A situation where no malicious activity exists and no threat is detected.
- **True Positive:** An alert that correctly identifies an actual attack.

## V
- **VirusTotal:** A service used to analyze suspicious files, domains, URLs, and IP addresses for malicious content.

## W
- **Wildcard:** A special character that can represent any other character or a set of characters.
- **Wireshark:** An open-source network protocol analyzer used to capture and inspect network traffic.

## Y
- **YARA-L:** A computer language used to create rules for searching through ingested log data.

## Z
- **Zero-Day:** An exploit that takes advantage of a previously unknown vulnerability.
