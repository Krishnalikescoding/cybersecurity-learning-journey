# Visual Dashboards and Security Communication

## 1. Visual Dashboards

A **visual dashboard** is a tool that displays different types of data in one place using charts, graphs, and tables.

**Purpose:**
- Present security information quickly.
- Help stakeholders understand security events.
- Communicate patterns, trends, and findings.
- Make complex numerical data easier to understand.

### Types of Dashboards

1. **Simple Dashboard:** Contains a single chart or graph.
2. **Complex Dashboard:** Contains multiple charts, graphs, and detailed tables.

**Tools used to create dashboards:**
- Google Sheets
- Apache OpenOffice

**Important:** Always ensure that data is accurate and represented correctly.

## 2. When to Use Visual Communication

Visual communication is especially useful when presenting large amounts of numerical data or comparing trends.

### Example: Phishing Email Audit

A supervisor asks for an audit report covering five departments over five months.

The audit records how many phishing emails employees clicked in each department.

Instead of explaining all the numbers through an email, a chart or graph can:
- Compare departments easily.
- Highlight departments with higher phishing click rates.
- Show trends over five months.
- Help stakeholders understand the findings quickly.

## 3. Choosing the Right Communication Method

| Situation | Recommended Method |
|---|---|
| Simple update | Email or instant message |
| Detailed explanation | Document attachment |
| Urgent communication | Phone call |
| Numerical data and trends | Charts, graphs, or dashboards |
| Complex findings | Visual presentation |

## 4. Key Takeaways

- Visual dashboards display important information in one place.
- They are especially useful for communicating numerical data and trends.
- Charts and graphs help stakeholders understand findings quickly.
- Choose simple or complex dashboards depending on the information being presented.
- Accuracy and attention to detail are essential when visualizing data.
- Keep stakeholder communication clear and concise.

**Remember:** Use text for explanations and visuals for patterns, comparisons, and numerical trends.
