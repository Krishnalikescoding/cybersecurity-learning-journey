# Module 3: Terms and Definitions

| Term | Definition |
|---|---|
| **AI Bias** | Bias in AI data or systems that can produce inaccurate, unfair, or unreliable results. |
| **Artificial Intelligence (AI)** | Computer programs designed to perform tasks associated with human intelligence, such as learning, problem-solving, and understanding language. |
| **Context (Prompting)** | Background information provided to an AI tool to help it understand the task. |
| **Evaluate (Prompting)** | Reviewing AI-generated output to determine whether it meets the required expectations. |
| **Generative AI (Gen AI)** | A type of AI that creates new content, such as text, images, code, and other media, in response to prompts. |
| **Human-in-the-Loop Approach** | A method of using AI with human supervision, review, and validation to ensure responsible and reliable results. |
| **Iterate (Prompting)** | Repeatedly refining prompts and outputs through testing and adjustments to achieve better results. |
| **OWASP Top 10** | A globally recognized awareness document listing the 10 most critical security risks to web applications. |
| **Prompt** | Input provided to an AI model to generate a specific response or new content. |
| **References (Prompting)** | Examples or specific information provided to an AI tool to guide its output. |
| **STAR Method** | A framework for explaining experiences using Situation, Task, Action, and Result. |
| **Stakeholder** | An individual or group with an interest in an organization's decisions or activities. |
| **Task (Prompting)** | The specific instruction or goal given to an AI model, including the desired output or format. |
| **TCREI Framework** | A framework for writing effective AI prompts: Task, Context, References, Evaluate, and Iterate. |
| **Visual Dashboard** | A tool that displays different types of data in one place for quick understanding and analysis. |

## Quick Revision

- **AI Bias:** Unfair or inaccurate AI results.
- **Gen AI:** AI that generates new content.
- **Prompt:** Input given to an AI model.
- **TCREI:** Task + Context + References + Evaluate + Iterate.
- **Human-in-the-loop:** AI with human supervision and validation.
- **OWASP Top 10:** Top 10 critical web application security risks.
- **STAR:** Situation + Task + Action + Result.
- **Visual Dashboard:** Displays data using charts, graphs, and tables.
- **Stakeholder:** Person or group interested in organizational decisions.
