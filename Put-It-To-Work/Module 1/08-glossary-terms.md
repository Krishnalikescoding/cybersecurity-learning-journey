# Course 8 – Module 1: Glossary

| Term | Definition |
|---|---|
| **Business Continuity Plan (BCP)** | A document outlining procedures to maintain business operations during and after a significant disruption. |
| **Confidential Data** | Data with restricted access, usually limited to a specific number of authorized people. |
| **Data Controller** | A person who determines the purpose and procedures for processing data. |
| **Data Processor** | A person or organization responsible for processing data on behalf of the data controller. |
| **Data Protection Officer (DPO)** | An individual responsible for monitoring an organization's compliance with data protection procedures. |
| **Disaster Recovery Plan (DRP)** | A plan outlining steps to minimize the impact of a security incident and recover affected systems. |
| **Escalation Policy** | A set of procedures defining who should be notified when an incident occurs and how it should be handled. |
| **Improper Usage** | An incident in which an employee violates the organization's acceptable use policies. |
| **Incident Escalation** | The process of identifying and triaging a potential security incident before transferring it to a more experienced team member. |
| **Malware Infection** | An incident in which malicious software enters an organization's computers or network. |
| **Private Data** | Information that should be kept from the public. |
| **Public Data** | Information accessible to the public that poses minimal risk to an organization if shared. |
| **Security Mindset** | The ability to evaluate risks and continuously identify potential or actual security breaches involving systems, applications, or data. |
| **Sensitive Data** | Data that includes PII, SPII, and PHI and requires strong protection from unauthorized access. |
| **Unauthorized Access** | An incident in which an individual gains digital or physical access to a system or application without permission. |

## Quick Revision

- **BCP:** Keeps business operations running.
- **DRP:** Helps recover systems after a disaster.
- **Public Data:** Open to everyone.
- **Private Data:** Not meant for public access.
- **Sensitive Data:** Requires strong protection.
- **Confidential Data:** Access restricted to authorized individuals.
- **Data Controller:** Decides why and how data is processed.
- **Data Processor:** Processes data for the controller.
- **DPO:** Monitors data protection compliance.
- **Incident Escalation:** Identifies, triages, and transfers incidents.
- **Escalation Policy:** Defines who to notify and how to report incidents.
