# Data Roles and Responsibilities

## 1. Data Owner
- Decides who can access, edit, use, or destroy specific data.
- Has administrative control over information, hardware, or software.
- Accountable for data classification, protection, access, and usage.

**When to escalate:** Unauthorized access to software or data should be reported to the relevant data owner.

## 2. Data Controller
- Determines the **purpose and procedure** for processing data.
- Decides how customers' personal information is collected and used.
- Ensures data is stored and processed according to security and privacy regulations.

**When to escalate:** Incidents involving risks to sensitive customer information.

## 3. Data Processor
- Processes data on behalf of the data controller.
- Usually a third-party vendor or service provider.
- May be responsible for implementing security measures to protect data.
- Reports directly to the data controller.

**When to escalate:** Data processing issues should be reported to the person overseeing the third-party organization.

## 4. Data Custodian
- Manages technical access to data and systems.
- Grants and revokes access to software or hardware.
- Implements security controls.
- Creates policies for storing and transmitting data.
- Advises on potential threats and monitors data security.

**When to escalate:** When security controls are compromised or need strengthening.

## 5. Data Protection Officer (DPO)
- Monitors an organization's compliance with data protection requirements.
- Advises the security team on data protection obligations.
- Conducts assessments to check whether security measures adequately protect data.

**When to escalate:** Violations of data protection standards or protocols.

## 6. Comparison of Data Roles

| Role | Main Responsibility |
|---|---|
| Data Owner | Decides who can access and control data |
| Data Controller | Determines why and how data is processed |
| Data Processor | Processes data on behalf of the controller |
| Data Custodian | Implements technical security controls and manages access |
| Data Protection Officer (DPO) | Monitors data protection compliance |

## 7. Key Takeaways

- Different team members have different responsibilities in protecting organizational data.
- Entry-level security analysts generally report incidents to their direct supervisor.
- Understanding these roles helps analysts identify the appropriate person or department for escalation.
- Effective incident escalation requires coordination between different teams.

**Remember:**
- **Owner = Controls data access and classification.**
- **Controller = Decides why and how data is processed.**
- **Processor = Processes data for the controller.**
- **Custodian = Implements technical protection and manages access.**
- **DPO = Ensures data protection compliance.**
