# How Programming Works

- **Programming:** The process of creating instructions that a computer executes to perform specific tasks.
- **Computer programs** are used in computers, smartphones, and other electronic devices.
- **Programming languages** are used to write these instructions in a human-readable form.
- Computers ultimately understand instructions as **binary (0s and 1s)**.
- Each binary instruction represents a specific **CPU operation**, such as:
  - Adding numbers
  - Loading values from memory
- Writing instructions directly in binary is difficult and time-consuming, so programming languages simplify the process.

## Using Python to Program

- **Python** is a **general-purpose programming language** used for many types of problems.
- Common uses include:
  - **Web development**
  - **Data analysis**
  - **Task automation**
- Python code is processed by an **interpreter**.
- **Interpreter:** A program that translates Python code into runnable instructions, generally **line by line**.

## Python Versions

- Multiple versions of Python exist.
- This course uses **Python 3**.
- Different Python versions can have differences in **syntax**.
- **Syntax:** The rules that determine how code must be correctly structured in a programming language.

## Python in Cybersecurity

Python is especially useful in cybersecurity for **automation**.

- **Automation:** Using technology to reduce human/manual effort in performing common and repetitive tasks.

### Cybersecurity Applications of Python
- **Log analysis**
- **Malware analysis**
- **Access Control List (ACL) management**
- **Intrusion detection**
- **Compliance checks**
- **Network scanning**

## Key Takeaways

- **Python is a programming language** used to create instructions for computers.
- Programming languages are ultimately converted into **binary instructions** that computers can understand.
- **Python 3** is the version used in this course.
