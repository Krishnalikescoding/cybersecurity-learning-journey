# Python Programming Environments

Python can be run through different **programming environments**, including:
- **Notebooks**
- **Integrated Development Environments (IDEs)**
- **Command line**

## Notebooks

- A **notebook** is an online interface for **writing, storing, and running code**.
- It also allows you to **document and explain code**.
- Notebook content is organized into:
  - **Code cells**
  - **Markdown cells**

### Code Cells

- Used to **write and execute Python code**.
- Code can usually be executed using a **play button** within the cell.
- The **output** appears after the code is executed.

### Markdown Cells

- Used to **describe and document code**.
- Support **Markdown language** for formatting plain text.
- Can be used for elements such as **headers** and other text formatting.

### Common Notebook Environments

- **[Jupyter Notebook](https://jupyter.org/about)**
- **[Google Colaboratory](https://colab.sandbox.google.com/) (Google Colab)**
- Both support Python and several other programming languages.

## Integrated Development Environments (IDEs)

- An **IDE** is a software application used for **writing and developing code**.
- Provides features such as:
  - **Editing assistance**
  - **Error correction**
  - **Graphical User Interface (GUI)**
  - Program customization and development tools

## Command Line

- The **command line** is a text-based environment used to interact with a computer through commands.
- A **Command-Line Interface (CLI)** allows users to:
  - Access files and directories
  - Run Python programs
  - Open file editors
  - Create new Python files

## Key Takeaways

- Python can be accessed through **notebooks, IDEs, and the command line**.
- This course primarily uses **notebooks**.
- Notebooks contain:
  - **Code cells** → Write and run code
  - **Markdown cells** → Describe and format text
- **IDEs** provide coding assistance and error correction.
- The **command line** allows Python programs and files to be managed using commands.
