# Terms and Definitions

**Application:** A program that performs a specific task.

**Basic Input/Output System (BIOS):** A microchip that contains loading instructions for a computer and is prevalent in older systems.

**Bootloader:** A software program that boots the operating system.

**Command-Line Interface (CLI):** A text-based user interface that uses commands to interact with a computer.

**Graphical User Interface (GUI):** A user interface that uses icons on the screen to manage different tasks on a computer.

**Hardware:** The physical components of a computer.

**Legacy Operating System:** An operating system that is outdated but still being used.

**Operating System (OS):** The interface between computer hardware and the user.

**Random Access Memory (RAM):** A hardware component used for short-term memory.

**Unified Extensible Firmware Interface (UEFI):** A microchip that contains loading instructions for a computer and replaces BIOS on more modern systems.

**User Interface:** A program that allows the user to control the functions of an operating system.
