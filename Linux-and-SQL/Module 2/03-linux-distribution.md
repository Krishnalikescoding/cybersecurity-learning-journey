# Linux Distributions for Cybersecurity

## Overview

A **Linux distribution (distro)** is a specific version of Linux that combines the Linux kernel with software packages and other components.

Different Linux distributions are designed for different purposes. Security analysts may encounter several distributions during their careers.

Common distributions discussed in this section include:

- Kali Linux
- Ubuntu
- Parrot
- Red Hat Enterprise Linux
- AlmaLinux
- CentOS

## Kali Linux

**Kali Linux** is an open-source, Debian-based Linux distribution widely used in the security industry.

Kali Linux is popular among security professionals because it comes with many pre-installed tools for:

- Penetration testing
- Digital forensics
- Security testing

**Penetration testing:** A simulated attack used to identify vulnerabilities in systems, networks, websites, applications, and processes.

**Digital forensics:** The practice of collecting and analyzing data to determine what happened after a security attack or event.

Kali Linux is not the only Linux distribution used in cybersecurity.

## Ubuntu

**Ubuntu** is an open-source and user-friendly Linux distribution widely used in security and other industries.

Features include:

- Command-Line Interface (CLI)
- Graphical User Interface (GUI)
- Debian-based architecture
- Common applications included by default
- Access to additional applications through a package manager
- Security-focused tools available through its software repositories

Ubuntu has a large community, providing extensive resources and support for users.

### Ubuntu in Cloud Computing

Ubuntu is also widely used for **cloud computing**.

As organizations migrate workloads to cloud servers, cybersecurity professionals may increasingly encounter Ubuntu and Ubuntu-based environments.

## Parrot

**Parrot** is an open-source Linux distribution commonly used for security-related tasks.

Like Kali Linux, Parrot includes pre-installed tools for:

- Penetration testing
- Digital forensics

Parrot is **Debian-based** and provides both:

- **CLI**
- **GUI**

Its graphical interface makes it accessible to users who prefer a user-friendly desktop environment.

## Red Hat Enterprise Linux

**Red Hat Enterprise Linux (RHEL)** is a subscription-based Linux distribution designed for enterprise use.

Key characteristics include:

- Enterprise-focused design
- Subscription-based model
- Professional support
- Dedicated customer support for technical issues

Unlike the previously discussed distributions, Red Hat Enterprise Linux is not provided as a free distribution in the same way as community-oriented distributions.

## AlmaLinux

**AlmaLinux** is a community-driven Linux distribution designed as a stable replacement for CentOS.

### Relationship with CentOS and Red Hat

**CentOS** was an open-source distribution closely related to Red Hat. It used source code published by Red Hat to provide a similar platform.

The final stable release of **CentOS 8** was released in December 2021.

AlmaLinux was designed to serve as a **drop-in replacement for CentOS 8**, allowing applications and configurations designed for CentOS to continue functioning on AlmaLinux.

## Linux Distribution Comparison

| Distribution | Base / Relationship | Common Use |
|---|---|---|
| **Kali Linux** | Debian-based | Penetration testing and digital forensics |
| **Ubuntu** | Debian-based | General computing, security, and cloud computing |
| **Parrot** | Debian-based | Penetration testing and digital forensics |
| **Red Hat Enterprise Linux** | Enterprise Linux | Enterprise environments |
| **AlmaLinux** | CentOS-compatible | Stable enterprise and server environments |
| **CentOS** | Closely related to Red Hat | Enterprise and server environments |

## Key Takeaways

- **Kali Linux** is a Debian-based distribution widely used for penetration testing and digital forensics.
- **Ubuntu** is a user-friendly distribution widely used in security, general computing, and cloud environments.
- **Parrot** is a Debian-based security distribution that includes penetration-testing and digital-forensics tools.
- **Red Hat Enterprise Linux (RHEL)** is a subscription-based distribution designed for enterprise environments.
- **AlmaLinux** is a community-driven distribution designed as a stable replacement for CentOS.
- Security analysts should be familiar with different Linux distributions because they may encounter several of them throughout their careers.
