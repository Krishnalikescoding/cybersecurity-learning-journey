# Terms and Definitions

---

## 1. Hardware Architecture

* **Hardware**: The tangible, physical components of a computer system.
* **Internal Hardware**: Essential physical components located inside the computer chassis required for system operation (e.g., motherboard, power supply).
* **Central Processing Unit (CPU)**: The primary processor responsible for executing machine instructions and handling general computing tasks.
* **Random Access Memory (RAM)**: High-speed, volatile hardware memory used for short-term data storage while programs are actively running.
* **Hard Drive**: Non-volatile storage hardware utilized for persistent, long-term data retention.
* **Peripheral Devices**: External hardware components connected to and controlled by the system (e.g., keyboard, mouse, monitor, external drives).

---

## 2. Operating System & Linux Core

* **Linux**: An open-source, Unix-like operating system kernel and family of operating systems.
* **Kernel**: The core component of the OS that directly bridges hardware and software, managing CPU processes, memory allocation, and system calls.
* **Shell**: The command-line interpreter that reads user inputs and executes instructions by communicating with the kernel.
* **Bash (Bourne Again SHell)**: The standard, default command shell across most Linux distributions.
* **Command**: A specific text instruction entered into a shell interface to execute a program or system utility.
* **Graphical User Interface (GUI)**: A visual interface employing windows, icons, and menus to interact with the OS instead of text commands.

---

## 3. Filesystem & Data Organization

* **Directory**: A specialized file structure used to store, organize, and group other files and subdirectories.
* **File Path**: The full address specifying the exact hierarchical location of a file or directory within the filesystem.
* **Filesystem Hierarchy Standard (FHS)**: The formal standard defining the organization, layout, and directory structure in Linux operating systems (e.g., `/etc`, `/var`, `/bin`).
* **String Data**: A basic data type consisting of a continuous, ordered sequence of characters.

---

## 4. Standard Input/Output (I/O) Streams

* **Standard Input (`stdin`)**: The default input data stream received by programs via the command line or pipeline (File Descriptor 0).
* **Standard Output (`stdout`)**: The default stream used by programs and the shell to send normal operational output data (File Descriptor 1).
* **Standard Error (`stderr`)**: The default stream reserved exclusively for error messages generated by programs or the OS (File Descriptor 2).

---

## 5. Software & Package Management

* **Application**: A complete program designed to execute specific end-user functions or tasks.
* **Package**: A compressed software archive containing compiled binaries, configuration files, and metadata required for application installation.
* **Package Manager**: A system tool (e.g., `apt`, `yum`, `dnf`) that automates software package installation, dependency resolution, upgrading, and removal.

---

## 6. Linux Distributions

* **Distributions (Distros)**: Tailored operating system releases combining the Linux kernel with specific package sets, default shells, and tools.
* **Ubuntu**: A widely deployed, user-friendly, Debian-based open-source distribution.
* **CentOS**: An open-source enterprise-class distribution historically derived from Red Hat upstream source code.
* **Red Hat® Enterprise Linux® (RHEL)**: A commercially supported, subscription-based distribution engineered for enterprise infrastructure.
* **Kali Linux™**: A specialized, Debian-derived distribution pre-configured with digital forensics and penetration testing toolsets.
* **Parrot OS**: A security-oriented, open-source Linux distribution optimized for penetration testing, vulnerability assessment, and privacy.

---

## 7. Security Concepts

* **Penetration Test (Pen Test)**: An authorized, simulated cyberattack against an organization’s systems, networks, or applications to identify exploitable security vulnerabilities.
* **Digital Forensics**: The structured process of identifying, preserving, extracting, and analyzing electronic evidence to reconstruct security breaches or incidents.
