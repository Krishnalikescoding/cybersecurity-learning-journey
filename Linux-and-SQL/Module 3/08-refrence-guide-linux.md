# Linux Reference Guide

## Overview

The **Linux reference guide** contains key Linux commands that security professionals use to perform basic job duties.

The guide is divided into six categories of Linux commands:

1. **Navigate the file system**
2. **Read files**
3. **Manage the file system**
4. **Filter content**
5. **Manage users and their permissions**
6. **Get help in Linux**

Within each category, commands are organized alphabetically.
