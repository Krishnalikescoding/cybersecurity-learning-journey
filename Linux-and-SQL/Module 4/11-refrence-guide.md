# SQL Reference Guide

## Overview

The **SQL reference guide** contains important SQL keywords that security analysts can use to query databases and find data that supports security-related decisions.

The guide is divided into four categories of SQL keywords:

- **Query a database**
- **Apply filters to SQL queries**
- **Join tables**
- **Perform calculations**

Within each category, the SQL keywords are organized alphabetically.
