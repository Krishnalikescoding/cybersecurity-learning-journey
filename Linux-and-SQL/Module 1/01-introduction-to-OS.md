# Operating Systems

## Overview

An **Operating System (OS)** is the interface between computer hardware and the user.

The OS is responsible for:

- Helping the computer operate efficiently
- Providing an interface for users to interact with the computer
- Managing multiple applications
- Providing access to external devices such as printers, keyboards, and mice
- Enabling communication between users and computer hardware

**Hardware:** The physical components of a computer.

Computers communicate using **binary**, which consists of `0`s and `1`s. The operating system provides an interface that allows users to interact with the computer without needing to communicate directly in binary.

## Evolution of Operating Systems

Early computers in the 1950s had significant limitations:

- They could not run multiple programs simultaneously.
- Users had to wait for one program to finish before running another.
- The computer had to be reset before loading a new program.

Operating systems evolved to improve computer efficiency and usability. Modern operating systems can:

- Run multiple applications simultaneously
- Manage external devices
- Provide user-friendly interfaces
- Help users interact with complex computer systems

## Operating System Security

Operating system security is essential for protecting computers from threats.

OS security involves:

- Securing files
- Controlling data access
- Managing user authentication
- Protecting against viruses, worms, and other malware
- Configuring and maintaining security controls

Security analysts may be responsible for:

- Managing access
- Configuring and maintaining firewalls
- Setting security policies
- Enabling virus protection
- Performing auditing and accounting
- Managing logs
- Detecting unusual behavior

Understanding how operating systems work is therefore important for performing security-related tasks.

## Common Operating Systems

Operating systems commonly encountered in the security industry include:

- Windows
- macOS
- Linux
- ChromeOS
- Android
- iOS

### Windows and macOS

Windows and macOS are commonly used on personal and enterprise computers.

| Operating System | Introduced | Source Code |
|---|---:|---|
| **Windows** | 1985 | Closed source |
| **macOS** | 1984 | Partially open source |

**Windows:** A closed-source operating system, meaning its source code is not freely shared with the public.

**macOS:** A partially open-source operating system containing both open-source and closed-source components. Its kernel includes open-source components.

### Linux

The first version of **Linux** was released in 1991, with other major releases following in the early 1990s.

Linux is completely open source, allowing anyone to access its source code. This enables developers within the Linux community to collaborate and contribute to its development.

Linux is particularly important in the cybersecurity industry because some Linux distributions are specifically designed for security-related tasks.

### ChromeOS

**ChromeOS** was launched in 2011.

- ChromeOS is partially open source.
- It is derived from **Chromium OS**, which is completely open source.
- ChromeOS is frequently used in education.

### Android and iOS

**Android** and **iOS** are mobile operating systems commonly used on:

- Smartphones
- Tablets
- Watches

| Operating System | Introduced | Source Code |
|---|---:|---|
| **Android** | 2008 | Open source |
| **iOS** | 2007 | Partially open source |

## Operating Systems and Vulnerabilities

Security issues can affect all operating systems.

One of the most important ways to protect an operating system is to keep the system and its components **up to date**.

Keeping operating systems updated helps protect against known security vulnerabilities and emerging threats.

## Legacy Operating Systems

**Legacy operating system:** An outdated operating system that is still being used.

Organizations may continue using legacy operating systems because software they depend on is incompatible with newer operating systems.

Legacy operating systems can be particularly common in industries that use equipment containing **embedded software**.

**Embedded software:** Software placed inside components of equipment.

### Security Risks of Legacy Operating Systems

Legacy operating systems can create security risks because they may no longer receive:

- Security updates
- Software updates
- Vulnerability patches
- Vendor support

As a result, they may remain vulnerable to newer threats.

Security analysts should understand the risks associated with legacy systems and account for them when securing an organization.

## Operating System Vulnerability Resources

Even fully updated operating systems can contain vulnerabilities. Security professionals can use vulnerability and security-update resources to identify known issues.

- [**Microsoft Security Response Center (MSRC):**](https://msrc.microsoft.com/update-guide/vulnerability) Provides information about known vulnerabilities affecting Microsoft products and services.
- [**Apple Security Updates:**](https://support.apple.com/en-us/HT201222) Provides security updates and information for Apple operating systems and products.
- [**Common Vulnerabilities and Exposures (CVE) Report for Ubuntu:**](https://ubuntu.com/security/cves) Provides information about known vulnerabilities affecting Ubuntu, a Linux distribution.
- [**Google Cloud Security Bulletin:**](https://cloud.google.com/support/bulletins) Provides information about vulnerabilities affecting Google Cloud products and services.

Keeping operating systems up to date is an important part of maintaining system security.

## Key Takeaways

- An **operating system** provides the interface between computer hardware and the user.
- Operating systems allow computers to efficiently run applications and interact with external devices.
- **Windows, macOS, Linux, ChromeOS, Android, and iOS** are commonly used operating systems.
- **Linux** is particularly important in cybersecurity because of its open-source nature and security-focused distributions.
- All operating systems can contain security vulnerabilities.
- Keeping operating systems and their components updated is an important security practice.
- **Legacy operating systems** are outdated systems that remain in use and may no longer receive security updates.
- Security analysts should understand operating system vulnerabilities and the risks associated with legacy systems.
